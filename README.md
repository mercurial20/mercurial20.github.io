# mercurial20.github.io

The website of [Loremapper](https://github.com/mercurial20/loremapper), a free, open-source fantasy map generator and editor:
pages about the editor in English and Russian, built with [Astro](https://astro.build) and published at
<https://mercurial20.github.io/>. The editor itself lives at <https://mercurial20.github.io/loremapper/>.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # into dist/
```

Astro needs Node.js 22.23 or later. Every push to `main` builds and publishes the site (GitHub Actions).
